# 途迹 TrekTrace - MVP 需求设计

> 创建时间：2026-04-06
> 状态：已确认

## 项目概述

户外运动记录 app，支持徒步、跑步、骑行，聚焦轨迹记录和数据统计。

**平台：** React Native（先 Android，后 iOS）

---

## MVP 功能范围

### 1. 运动记录
- **三种模式：** 徒步 / 跑步 / 骑行
- **GPS 轨迹：** 实时绘制路线
- **实时数据：** 距离、时长、配速/时速、海拔
- **控制：** 开始 / 暂停 / 继续 / 结束

### 2. 数据统计
- **历史列表：** 按时间排序，可筛选运动模式
- **总览面板：** 总里程、总时长、总次数
- **单次详情：** 轨迹回放、海拔曲线、配速分布
- **导出：** 支持 GPX 格式

### 3. 用户体系
- **登录方式：** 手机号 + 验证码
- **短信服务：** 阿里云/腾讯云短信
- **数据同步：** 云端存储

---

## 技术栈

| 层 | 方案 |
|---|---|

| 地图 | 高德地图 SDK |
